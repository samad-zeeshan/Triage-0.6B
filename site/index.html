Triage

Triage reads a support email and returns its topic, urgency and account number as clean JSON. It is a 600-million-parameter model that runs on one ordinary graphics card with no internet. It says how sure it is, and the unsure emails go to a bigger model.

For the person who opens the support inbox in the morning and has to sort it before anyone can start work.
